    33	
    34	    private final FirebaseMessaging firebaseMessaging;
    35	
    36	    @Override
    37	    public FcmSendResult send(FcmSendRequest request) {
    38	        if (request.targets().isEmpty()) {
    39	            return FcmSendResult.of(0, 0, List.of());
    40	        }
    41	
    42	        try {
    43	            BatchResponse response = firebaseMessaging.sendEachForMulticast(toMessage(request));
    44	            return toResult(request.targets(), response);
    45	        } catch (FirebaseMessagingException e) {
    46	            log.error("FCM 배치 발송 실패: tokenCount={}", request.targets().size(), e);

    48	        }
    49	    }

    52	        Notification.Builder notificationBuilder = Notification.builder()
    53	            .setTitle(request.title())
    54	            .setBody(request.body());
    55	        if (request.imageUrl() != null && !request.imageUrl().isBlank()) {
    56	            notificationBuilder.setImage(request.imageUrl());
    57	        }
    58	
    59	        MulticastMessage.Builder messageBuilder = MulticastMessage.builder()
    60	            .addAllTokens(request.targets().stream().map(FcmSendTarget::token).toList())
    61	            .setNotification(notificationBuilder.build());
    62	
    63	        Map<String, String> data = new HashMap<>(request.data());
    64	        if (request.deepLink() != null && !request.deepLink().isBlank()) {
    65	            data.putIfAbsent("deepLink", request.deepLink());
    66	        }
    67	        if (!data.isEmpty()) {
    68	            messageBuilder.putAllData(data);
    69	        }
    70	
    71	        return messageBuilder.build();
    72	    }
    73	
    74	    private FcmSendResult toResult(List<FcmSendTarget> targets, BatchResponse response) {
    75	        List<Long> invalidTokenIds = new ArrayList<>();
    76	        List<SendResponse> responses = response.getResponses();
    77	        for (int i = 0; i < responses.size(); i++) {
    78	            SendResponse sendResponse = responses.get(i);
    79	            if (isUnregistered(sendResponse)) {
    80	                invalidTokenIds.add(targets.get(i).tokenId());
    81	            }
    82	        }
    83	        return FcmSendResult.of(response.getSuccessCount(), response.getFailureCount(), invalidTokenIds);
    84	    }
    85	
    86	    private boolean isUnregistered(SendResponse response) {
    87	        return !response.isSuccessful()
    88	            && response.getException() != null
    89	            && MessagingErrorCode.UNREGISTERED.equals(response.getException().getMessagingErrorCode());
    90	    }

Additional security evidence added after final code review:

`FcmRegistrationRequest` accepts `fcmToken` with `@NotBlank` only; there is no size limit on the token field.
```

```

`FcmService.registerFcmToken` deactivates tokens owned by other members, but for the same member it upserts only an exact `(memberId, fcmToken)` match and otherwise saves a new active token. There is no per-member active-token cap in this service path.
```

src/main/java/com/umc/product/notification/application/service/FcmService.java:27

src/main/java/com/umc/product/notification/application/service/FcmService.java:35
```

`FcmToken.register` sets `lastValidatedAt` to registration time, while the default validation stale duration is 30 days. This can delay cleanup for newly registered invalid/oversized tokens.
```
src/main/java/com/umc/product/notification/domain/FcmToken.java:91
src/main/java/com/umc/product/notification/domain/FcmToken.java:97
src/main/resources/application.yml:336
```

Normal send failure handling marks only `UNREGISTERED` invalid, while token validation dry-run treats `UNREGISTERED` and `INVALID_ARGUMENT` as invalid. This makes malformed token cleanup more dependent on the scheduled validation path.
